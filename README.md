# Chiguru – AI & IoT Powered Smart Agriculture App
Empowering farmers with real-time, localized, and intelligent farming decisions through a unified mobile platform.

## Installation

To get started with the project locally:

**Clone the repository**
```bash
git clone https://github.com/abhishekraooo/smart_crop_management.git
cd smart_crop_management
```

**Install dependencies**
```bash
flutter pub get
```

**Run the app on emulator or connected device**
```bash
flutter run
```
